# AGENTS.md — Personal Portfolio Project

Este archivo define las directrices, la identidad visual, la arquitectura y las reglas de diseño para la creación de tu portfolio personal. Está optimizado para que cualquier agente de IA (o tú mismo) entienda el propósito, el tono y la implementación técnica rápidamente.

---

## 1. Visión General del Proyecto

* **Propietario:** Erik (`@ErikWebDeveloper`)
* **Ubicación / Contexto:** Andorra 🇦🇩
* **Propósito:** Un portfolio personal moderno, minimalista, intuitivo y con una fuerte identidad visual que refleje tu perfil polivalente como desarrollador, *builder* y creador.
* **Estética (Neo Cozy Cyberpunk + Pixel Art):**
* *Neo Cozy Cyberpunk:* Combina la atmósfera nocturna, luces de Neón suaves (púrpuras, cianes cálidos, ámbar tenue) y pantallas de terminal con una sensación acogedora, limpia y sin saturar (espacios oscuros limpios, tipografías monoespaciadas cuidadas, calidez hogareña frente al frío digital puro).
* *Pixel Art:* Detalles sutiles y nostálgicos (pequeños iconos o divisores pixelados, animaciones de carga tipo 8-bit, cursores personalizados o bordes estilo retro) integrados en una interfaz moderna, limpia y fluida.



---

## 2. Directrices de Diseño y UX

* **Minimalismo e Intuitividad:** Cero ruido visual. Menos es más. Estructura limpia donde cada elemento tiene un propósito. Las secciones deben fluir de forma natural sin sobrecargar al usuario con animaciones molestas.
* **Tipografía:**
* Fuente principal/títulos: Una fuente monoespaciada con carácter (ej. *JetBrains Mono* o *Fira Code*) combinada con una fuente sans-serif limpia para lectura fluida (ej. *Inter* o *Geist*).


* **Paleta de Colores Base (Dark Mode Core):**
* **Fondo Principal:** Negro carbón profundo o azul medianoche oscuro (`#0b0f19` / `#121214`).
* **Acentos Neón Cálidos / Cozy:** Cian suave (`#38bdf8`), Ámbar/Terminal (`#f59e0b` o verde fósforo suave `#34d399`) y Púrpura cyberpunk apagado (`#a855f7`).
* **Textos:** Gris claro de alta legibilidad (`#e2e8f0` para principal, `#94a3b8` para secundario).



---

## 3. Arquitectura de Contenidos

El portfolio se estructurará en una sola página fluida (*Single Page Application* o web estática modular) dividida en secciones claras:

1. **Hero Section (Presentación):**
* Saludo directo con un toque pixel art o terminal (`👋 Hi, I'm Erik`).
* Breve bio dinámica: *Software Developer · Builder · AI Enthusiast*.
* Indicador sutil de disponibilidad / ubicación (Andorra 🇦🇩).


2. **Lo que Hago / Enfoque (What I Build):**
* Tarjetas minimalistas o lista interactiva que agrupen tus pasiones: Web apps, Mobile, Mini juegos, Herramientas CLI, IA local y Audio/DSP.


3. **Proyectos / Experimentos (Showcase):**
* Enfoque en destacar tanto productos pulidos como "experimentos y prototipos" (demostrando que construir por aprender es valioso).
* Tarjetas con enlace directo a GitHub / Demo, etiquetas de tecnologías flexibles y estética ligeramente cyberpunk/terminal.


4. **Stack Tecnológico (Tooling & Interests):**
* Una sección limpia que muestre tu flexibilidad técnica (JavaScript, TypeScript, Node.js, Three.js, Linux, Docker, Python, etc.) sin caer en listas aburridas de porcentajes.


5. **Contacto / Footer:**
* Enlaces directos a Correo (`erikcodedeveloper@gmail.com`), GitHub y un toque final con agradecimiento en japonés (`ありがとうございます 🙏`).

## 4. Instrucciones para la Implementación (Prompt para IA / Desarrollo)

Cuando comiences a desarrollar este portfolio utilizando herramientas como HTML/CSS/JS, un framework moderno o componentes estáticos, sigue estas reglas estrictas:

* **Clean Code:** Mantén el código modular, limpio y bien comentado.
* **Performance:** Carga rápida, optimización de fuentes y assets ligeros (especialmente si usas detalles en pixel art o SVG).
* **Responsive First:** El diseño cyberpunk y acogedor debe verse igual de bien en pantallas ultra-anchas de desarrollador como en dispositivos móviles.
* **Interactividad Sutil:** Pequeños efectos al pasar el ratón (efecto glow suave, sonidos de terminal opcionales o cambios de color sutiles estilo neón).
